# Exploratory Data Analysis (EDA) on Retail Sales Data

## Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on a retail menu dataset to identify patterns, trends, and meaningful insights.

## Tasks Performed
- Data loading and cleaning
- Descriptive statistical analysis
- Category and product analysis
- Data visualization (bar chart, line plot, heatmap)
- Insight generation and recommendations

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Learnings
- Data preprocessing and cleaning
- Statistical analysis
- Data visualization
- Insight generation from data

## Outcome
Analyzed the dataset to uncover trends, compare categories, and generate insights that can support better business decisions.
